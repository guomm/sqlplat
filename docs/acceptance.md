## 默认限制

单 API 进程、单实例；4 个执行线程、20 个等待任务；不提供手动事务、SQL 自动重试、定时 SQL 或取消操作。当前编辑器不提供 DELIMITER/存储过程编辑工作流。超时与断线后的写入状态需要目标数据库核实，平台不承诺自动回滚。

Excel 单元格超过 32767 字符时受格式长度限制，非法 XML 控制字符替换为可见替代字符；原始长文本可通过 CSV 获取。
